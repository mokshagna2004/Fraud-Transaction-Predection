# Fraud Transaction Prediction

- Developed fraud detection models using Random Forest and XGBoost to identify suspicious transactions in a highly imbalanced dataset of 6.36 million transactions.
- Evaluated model performance using ROC-AUC, precision, and recall, achieving a 99.97% ROC-AUC with XGBoost and identifying 2,138 fraudulent transactions in the test set.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Random Forest, XGBoost, Machine Learning
